## Project Overview
This is a multi-page website built for Sweet Crumbs Bakery, a fictional bakery business founded by Lindiwe Dube in 2017. The site includes a home page, an about page, a products page, an enquiry form, and a contact page.

## Goals
- Build a clean, easy-to-navigate website for a small bakery business
- Apply responsive design so the site works well on desktop, tablet, and mobile
- Practice semantic HTML, CSS layout techniques (Flexbox and Grid), and basic JavaScript form handling

## Features
- Responsive navigation header
- Home page hero section with a call-to-action button
- About page with the bakery's story and mission
- Products page with a grid of menu items and photos
- Enquiry form with client-side validation and a confirmation message
- Contact page with business details
- Custom logo and real photography throughout the site

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, media queries)
- JavaScript (form validation)
